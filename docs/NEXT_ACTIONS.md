# 다음 할 일 (Next Actions) — 작업 이어가기

> 환경(회사↔집)을 옮겼을 때 "무엇을 하려던 참이었지?"를 즉시 복원하기 위한 메모다.
> `./sync-check.sh` 를 실행하면 이 내용이 자동으로 표시된다.
> **작업을 마칠 때마다 이 파일을 갱신한다.** (전체 히스토리·이유는 `DECISION_LOG.md`, 여기는 "지금/다음"만 짧게.)

## 🔁 작업 루틴 (엇나감 방지 — 이것만 지키면 됨)

두 PC(회사↔집)가 절대 엇나가지 않으려면 **딱 두 명령**만 기억하면 된다(사실 기억 안 해도 됨):

- **시작할 때 →** `./sync-check.sh`   (원격 최신 받기 + 상태 + 다음 할 일 표시)
- **끝낼 때 →** `./save.sh "메모"`   (변경 커밋 + 원격 합치기 + GitHub에 올리기, 한 방)

> 원칙: **항상 한 번에 한 PC에서만** 작업하고, 끝나면 반드시 `save.sh`. 다음 PC에선 `sync-check.sh`로 시작.
> 두 PC에서 동시에 손대 충돌(diverge)이 나도 `save.sh`가 `pull --rebase`로 합쳐준다(충돌 시 안내).
